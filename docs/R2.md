# R2 配置指南

## 1. 创建 Bucket

Cloudflare Dashboard → R2 → Create bucket → `tnexus-assets`

## 2. API Token

R2 → Manage R2 API Tokens → Create API token

- Permissions: Object Read & Write
- Scope: `tnexus-assets` bucket only

记录：
- Account ID → `R2_ACCOUNT_ID`
- Access Key ID → `R2_ACCESS_KEY_ID`
- Secret Access Key → `R2_SECRET_ACCESS_KEY`

## 3. 定价（MVP）

| 项 | 费用 |
|----|------|
| 存储 | $0.015/GB/月（免费 10GB） |
| 出站 | **$0** |
| PUT | $4.50/百万（免费 100万/月） |
| GET | $0.36/百万（免费 1000万/月） |

## 4. 域名

- 应用：`tnexus.closeapi.top` → Panda `:9000`（CF 代理 + HTTPS）
- 资产：通过 presigned URL 访问，无需公开 Bucket

## 5. 带宽路径

```
用户下载 ← Cloudflare CDN ← R2（零 Panda 上行）
Panda Worker：上游拉图（200Mbps 下行）→ 上传 R2（30Mbps 上行，每图一次）
```
